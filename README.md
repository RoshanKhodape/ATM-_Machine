# ATM Machine Simulation using Python

## Project Overview
A simple ATM simulation developed using Python.

## Features
- PIN Authentication
- Cash Deposit
- Cash Withdrawal
- Balance Inquiry
- Multiple Transactions
- Input Validation
- Error Handling

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Run the following command:

   python ATM.py

## Learning Outcomes
- Conditional Statements
- Loops
- Exception Handling
- User Input Validation
- Basic Banking Logic
